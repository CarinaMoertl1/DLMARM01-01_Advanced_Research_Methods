# DLMARM01-01 Advanced Research Methods

Stock-direction evaluation code and figures for the main and confirmation samples.

## Contents

- `stock_evaluation.py` - evaluation pipeline.
- `stock_sample_assignments.csv` - maps the 40 pilot stocks to the main and confirmation samples.
- `Plots/` - publication-ready PNG and PDF figures.

Raw stock-price data and generated tabular run outputs are excluded from this repository.
